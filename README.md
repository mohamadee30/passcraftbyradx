PassCraft is an all-in-one Python-based security suite designed for password generation, hashing, encoding/decoding, hash cracking, and basic penetration testing tasks.

## 🚀 Features







- **Wordlist Generator:** Generate custom targeted wordlists based on personal info, dates, and patterns.
- **Hash Cracker:** Crack hashes using custom wordlists.
- **Hash Type Identifier:** Automatically identify hash types based on string length.
- **Encoder / Decoder & Hash Suite:** Supports Base64, URL encoding/decoding, MD5, and SHA-256 generators.
- **SSH Brute Forcer:** Multi-threaded SSH login cracker powered by Paramiko.
